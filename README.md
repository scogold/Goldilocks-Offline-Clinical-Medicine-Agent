Goldilocks is an offline clinical assistant that helps authorized clinic personnel find and understand information contained in approved local medical protocols. A user asks a question in Spanish or English, and the system retrieves the most relevant passages from a curated local document library. A locally running language model then produces a concise Spanish answer with citations to the original document and page.
The project is designed for settings where internet connectivity is absent, unreliable, expensive, or inappropriate for sensitive health information. All model inference, document search, and answer generation occur locally on the deployment computer.
Goldilocks is not an autonomous medical provider. The first version will not diagnose patients, prescribe treatment, calculate medication doses, interpret imaging or laboratory results, or determine patient disposition. Its purpose is narrower: make approved clinical knowledge easier to locate while leaving all medical decisions with qualified healthcare professionals.
