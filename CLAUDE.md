# Goldilocks — An Offline Clinical Medicine Agent

## Project Overview
Goldilocks is an offline-first clinical medicine agent designed to assist healthcare professionals with diagnostic reasoning, treatment guidelines, drug references, and clinical decision support — without requiring internet connectivity.

## Goals
- Run fully offline on local hardware
- Provide evidence-based clinical decision support
- Support differential diagnosis generation
- Offer drug dosing, interactions, and contraindication references
- Remain within scope: decision support only, not prescriptive diagnosis
